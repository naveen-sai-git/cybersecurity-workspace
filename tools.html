03 / SECURITY TOOLS

Your tool belt
for the mission.

A curated directory of the most essential cybersecurity tools, organized by discipline so you can find exactly what you need.

01 / DISCOVERY

Know the right tool for every job.

Security work demands the right instrument for each task. Reconnaissance requires different tools than forensics. Exploitation requires different skills than defence.

CYBERM organises the essential toolkit by discipline so you spend less time searching and more time working.

02 / RECONNAISSANCE

Gather
intelligence.

Nmap

The gold standard for network discovery and security auditing. Scan ports, detect services, and identify OS fingerprints.

Open Tool

Shodan

Search engine for internet-connected devices. Discover exposed systems, open ports, and misconfigured services worldwide.

Open Tool

theHarvester

OSINT tool for gathering emails, subdomains, IPs, URLs and names from public sources like Google, LinkedIn, and Shodan.

Open Tool

Maltego

Visual intelligence and link analysis platform. Map relationships between people, organizations, domains, and infrastructure.

Open Tool

Recon-ng

Full-featured web reconnaissance framework written in Python. Modular design for systematic OSINT gathering.

Open Tool

OSINT Framework

Collection of 500+ OSINT resources organized by category. Your starting point for any open-source intelligence investigation.

Open Tool
03 / WEB SECURITY

Test web
applications.

Burp Suite

The leading web application security testing platform. Intercept, modify, and replay HTTP requests with a full scanner and extension ecosystem.

Open Tool

OWASP ZAP

Free and open-source web application scanner. Excellent for beginners and CI/CD pipeline integration. Maintained by OWASP.

Open Tool

SQLmap

Automated SQL injection detection and exploitation tool. Supports database fingerprinting, data extraction, and shell access.

Open Tool

Nikto

Open-source web server scanner that performs comprehensive tests against servers for dangerous files, outdated software, and misconfigurations.

Open Tool

Dirb / Gobuster

Web content discovery tools. Brute-force directories and file names on web servers to uncover hidden resources and entry points.

Open Tool

Wfuzz

Flexible web application fuzzer. Used for brute-forcing GET and POST parameters, headers, cookies, and form fields.

Open Tool
04 / NETWORK ANALYSIS

Analyse
the wire.

Wireshark

The world's most widely used network protocol analyser. Capture and inspect packets in real time or from saved captures.

Open Tool

Nessus

Comprehensive vulnerability scanning platform. Identifies over 67,000 CVEs across network devices, cloud, containers, and endpoints.

Open Tool

OpenVAS

Open-source vulnerability assessment system. Full-featured network scanner maintained by Greenbone for enterprise and personal use.

Open Tool

Metasploit

The world's most used penetration testing framework. Thousands of exploits, auxiliary modules, and payloads for security testing.

Open Tool

Netcat

The "Swiss army knife" of networking. Read and write data across network connections. Essential for debugging, port scanning, and backdoors.

Open Tool

Aircrack-ng

Complete suite for assessing WiFi network security. Packet capture, replay attacks, and WEP/WPA cracking in a single toolkit.

Open Tool
05 / FORENSICS

Investigate
the evidence.

Autopsy

Digital forensics platform and GUI for The Sleuth Kit. Analyse hard drives, smartphones, and disk images with timeline analysis.

Open Tool

Volatility

Advanced memory forensics framework. Extract artifacts from RAM dumps — processes, network connections, registry keys, and malware traces.

Open Tool

Binwalk

Firmware analysis tool for extracting and reverse-engineering embedded firmware images. Used in IoT and hardware security research.

Open Tool

FTK Imager

Industry-standard disk imaging tool from AccessData. Create forensically sound images and preview evidence without altering original data.

Open Tool

Ghidra

NSA's open-source reverse engineering framework. Disassemble and decompile binaries across multiple architectures for malware analysis.

Open Tool

ExifTool

Read, write, and edit metadata in files. Reveal GPS coordinates, camera data, software used, and modification timestamps in images and documents.

Open Tool
06 / PASSWORD & CRYPTO

Break and
understand hashes.

Hashcat

The world's fastest and most advanced CPU-based password recovery utility. Supports GPU acceleration and 300+ hash types.

Open Tool

John the Ripper

Classic open-source password security auditing and recovery tool. Supports over 15 hash formats with dictionary, brute-force, and hybrid attacks.

Open Tool

CyberChef

The "Cyber Swiss Army Knife." Browser-based tool for encoding, decoding, encrypting, hashing and data analysis with drag-and-drop operations.

Open Tool

Hydra

Fast and flexible online password cracking tool. Supports 50+ protocols including SSH, FTP, HTTP, SMB, SMTP and more.

Open Tool

GnuPG

Complete implementation of the OpenPGP standard. Encrypt and sign data, manage keys, and authenticate communications securely.

Open Tool

hashID

Tool to identify different types of hashes. Input an unknown hash and get a list of possible hash algorithms that could have produced it.

Open Tool
