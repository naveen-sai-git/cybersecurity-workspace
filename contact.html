03 / FAQ

Common
questions.

01
Is CYBERM completely free?
Yes. Roadmaps, tools directory, developer utilities, guides, and security news are all free with no registration required. We may introduce optional premium features in the future, but the core platform will always remain free.
02
Do the utilities send my data anywhere?
No. All utility tools (Base64, Hash, JWT Decoder, Subnet Calculator, etc.) run entirely in your browser using client-side JavaScript. No input you enter is transmitted to any server. Your data never leaves your machine.
03
How do I suggest a tool, guide, or resource?
Use the contact form above, select "Tool / resource suggestion" as the topic, and describe what you'd like to see added and why. We review every suggestion and add the most-requested items regularly.
04
Can I contribute content to CYBERM?
Absolutely. We welcome guide contributions from experienced practitioners. If you want to write a guide, create a cheat sheet, or contribute to the tools directory, reach out via the contact form with "Partnership / collaboration" selected.
